新供应商全流程引入与上线

End-to-End Supplier Onboarding

背景 / CONTEXT

公司业务扩张需扩充合作资源池，需打通从商务拓展、准入评估到上线运营、履约管控的全流程，保障新供应商高效、合规落地。

动作 / WHAT I DID
  1. 资源对接通过行业展会、资源对接会等渠道挖掘潜在合作方，牵头完成供应商准入全维度评估，涵盖资质审核、价格竞争力对比、技术参数核验、风险排查，累计对接潜在供应商 30+ 家。

  3. 运维优化上线后建立周期考核机制，持续监测运营数据与履约表现，定期输出分析复盘，推动合作服务质量持续优化。

2026.06 — 至今 项目负责人

数据监控体系搭建

Supplier Monitoring & Alerting System

背景 / CONTEXT

随着境内外合作供应商数量快速增长，多区域、多 API 接口的管理复杂度显著提升；原有依赖人工统计的模式存在指标口径不统一、履约异常发现滞后、对账核算效率低等问题，牵头搭建自动化数据监控体系。

动作 / WHAT I DID
  1. 指标体系梳理供应商全业务链路节点，搭建资源供给、接口稳定、履约质量、结算合规 4 大类核心指标体系，统一统计口径与数据来源，输出标准化指标管理手册，覆盖 20+ 项核心运营指标。
  2. 可视化看板基于 Superset 搭建分层看板，覆盖日度实时监控、周度履约复盘、月度结算核对、专项供应商管控四大场景，对接业务数据库实现数据自动更新与多维度下钻。
  3. 预警机制设计三级智能预警，针对报价成功率、接口响应时效、结算异常等高敏感指标设置分级阈值，联动内部渠道自动推送告警，配套「预警–处置–复盘」闭环流程。
  4. 推广落地联动产品、技术团队落地自动化管控功能需求，将监控体系嵌入供应商准入–上线–履约–结算全流程，完成团队操作培训与落地推广。
成果 / RESULTS

跨部门供应商数据一致性提升至 98%，人工统计与对账工时降低 60%；供应商履约异常平均响应时长从 4 小时缩短至 30 分钟，渠道接口故障率下降 21%，整体供应商履约达标率提升 15%。
